这一版新增「自定义 (System One 决策模型)」入口，可以把局域网或第三方的 Jev / Clef 决策模型端点手动接进 model-jev；同时修复了长时间流式生成在 10 分钟处被切断的问题。升级后已有订阅的行为不变。

## 新功能
- **自定义 System One 决策模型入口**：添加订阅时，在厂商下拉的「自定义」分组里选「自定义 (System One 决策模型)」，手动填写 Base URL、接口路径、API Key 与 Jev 模型，适合局域网里另一台机器上的 Ollama、自建网关或其他第三方托管。
  - 订阅只能绑定到 `model-jev`，请求原样转发，不做协议转换。
  - 鉴权方式可选 `Authorization: Bearer` 或 `x-api-key`；上游不校验 API Key 时填任意值即可。
  - Jev 模型必填：自定义订阅没有示例模型可以回退，留空或只填空格都无法保存，编辑时也不能清空。内置 System One 订阅的 Jev 模型仍然可以留空。
  - 终端界面的新建向导同样支持，选这个协议时表单里只有一行 Jev 模型。
  - 请求 `model-jev` 时，既没有配置 Jev 模型、也没有示例模型的订阅会被跳过，由其他订阅继续处理；全部不可用时返回 503 并写明原因，不再让整个请求返回 400。

## 修复
- **长时间的流式生成在 10 分钟处被切断**（#59，感谢 @WayneOffice 报告）：此前转发到上游的请求有 600 秒的总时长上限，生成超过 10 分钟的流式响应会在中途断开。现在改为空闲超时：上游连续 600 秒没有返回任何数据才断开，持续输出的长生成不再受限。非流式请求的等待上限仍是 600 秒。
  - 超时时的报错从「error decoding response body」改为「等待上游数据超时, 连接已断开」。
