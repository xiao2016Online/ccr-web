這一版新增繁體中文介面，並讓訂閱的每個模型槽位可以依星期和時段換用不同模型；另外新增「自動檢查更新」開關。注意：模型槽位留空的訂閱升級後不再被呼叫，詳見「其他」。

## 新功能
- **繁體中文介面**：設定 → 通用 → 介面語言 裡可以選「繁體中文」，用詞依台灣習慣，港澳共用。
  - 涵蓋桌面介面、網頁介面、終端機介面、系統匣選單、廠商名稱與說明，以及這份更新內容。
  - 「跟隨系統」時，繁體中文（台灣 / 香港 / 澳門）與粵語系統顯示繁體中文，其餘中文系統仍顯示簡體中文。
  - 中日文字型依介面語言切換，繁中與日文不再以簡中字形顯示。
- **模型槽位依時段切換模型**（#62，感謝 @WayneOffice 建議）：適合同一訂閱白天、夜裡分別對不同模型有優惠的情況。在訂閱編輯頁的「模型槽位」卡片裡設定。
  - 每個槽位有一個預設模型，外加最多 16 條有順序的時段規則：選星期（每天 / 工作日 / 週末 / 自訂）、起訖時間（精確到半點，可以跨午夜）和模型，排在前面的規則優先。
  - 每條時段可以單獨設定思考強度，選「跟隨槽位」時使用預設模型後面設的思考強度。
  - 預設模型可以選「不設定（時段外無法使用）」：規則之外的時間，這個訂閱不參與該槽位的調度，請求交給虛擬模型綁定的其他訂閱。
  - 右側即時顯示一週預覽，並提示被前面規則完全蓋住的時段、一週都無法使用的槽位；「複製到其他槽位」可以把目前槽位的安排複製給其餘三個。
  - 時間以執行 cc-router 的電腦為準，在請求到達時判斷，不會改寫已儲存的設定。
  - 虛擬模型頁改為路由圖：每個虛擬模型展開到訂閱、再到每條時段規則，標出此刻會命中的那一行；頂部「查看時刻」可以拖到一週裡的任意半點，看那時請求會怎麼走，一週裡沒有訂閱可用的時段會標紅。
  - 終端機介面的訂閱頁顯示每個槽位此刻生效的模型，有時段規則的槽位帶「分時段」標記。
  - 測試連線依此刻生效的模型與思考強度送出。
- **自動檢查更新開關**（預設開）：設定 → 通用 → 應用更新 → 自動檢查更新，檢查更新頁也有同一個開關。關閉後啟動時不再連網查詢新版本，只在你手動檢查時查詢。

## 修復
- **測試連線失敗時看不出結果**（#63）：上游回傳空的錯誤內容時，介面以前只剩一行「測試模型」。現在失敗時一律顯示「連線失敗」標題和原因，例如「HTTP 401」加上游錯誤內容的前 300 個字元。
- **Linux deb 版啟動時的自動檢查忽略「更新源」設定**：以前啟動檢查早於設定載入，總是查詢全球源；現在依你選的更新源查詢。

## 其他
- **模型槽位留空的訂閱不再被呼叫**：以前槽位留空時，請求會帶著空的模型名稱送給上游，依賴這一點的本機服務（如 llama.cpp）可以照常運作；現在槽位此刻沒有模型的訂閱會被略過，由其他訂閱處理，都無法使用時回傳 503 並寫明原因。給這個槽位隨便填一個模型名稱即可恢復原來的行為。
- **訂閱編輯頁版面調整**：
  - 「用量額度」的設定和用量進度合併成一張卡片，每個週期一行：額度、用量條和恢復時間；沒設額度的週期也顯示已用量。
  - 「餘額」不再單獨成卡，放在「基本資訊」右側，視窗較窄時折到欄位下方。
- **README 新增繁體中文版**。
- **升級相依套件，處理安全性警示**：涉及開發伺服器與間接引入的套件，對已安裝的 app 沒有可利用的路徑。
